# Marketing Automation Templates

Starter automations mapped onto the Marketing Automation course. See the [repo root README](../README.md) for the disclaimer and design principles shared by every template here.

| Template | What it does |
|---|---|
| [Campaign Automation](campaign-automation/) | Trigger/condition/action drip sequence — dry-run simulator, never sends live |
| [Lead Scoring & Routing](lead-scoring-routing/) | Weighted engagement score + round-robin/territory routing |
| [Content & Social Automation](content-social-automation/) | Rotating content calendar + rule-based caption variants |
| [KPI Dashboard](kpi-dashboards/) | GA + CRM rollup — CAC, MQL→SQL conversion |
| [A/B Test Runner](ab-testing/) | Two-proportion z-test — flags a real winner, or tells you it's not significant yet |
| [UTM Consistency Checker](utm-consistency-checker/) | Validates campaign URLs against your UTM naming convention pre-launch |
| [Landing Page Headline Variant Generator](headline-variant-generator/) | Rule-based headline/subhead variants for A/B testing |
| [Email List Hygiene Bot](email-list-hygiene/) | Flags malformed/bounced/inactive subscribers — never unsubscribes automatically |
| [Webinar Follow-Up Automation](webinar-followup/) | Segments attended vs. no-show, recommends the right next step per segment |
| [SEO Keyword Gap Tracker](seo-keyword-gap-tracker/) | Finds keywords a competitor ranks for that you don't |
| [Content Performance Scorer](content-performance-scorer/) | Weighted engagement score — tells you what to repurpose |
| [Ad Budget Pacing Monitor](ad-budget-pacing-monitor/) | Flags campaigns over/under monthly spend pace |
| [Event/Trade Show Lead Router](trade-show-lead-router/) | Routes scanned leads by territory/interest, ready for CRM import |
| [Referral Program Tracker](referral-program-tracker/) | Calculates rewards owed per referrer — never issues payment automatically |
| [Brand Mention Monitor](brand-mention-monitor/) | Keyword-based triage of social mentions — urgent items surfaced first |
