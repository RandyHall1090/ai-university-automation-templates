# Sales Automation Templates

Starter automations mapped onto the Sales Automation course. See the [repo root README](../README.md) for the disclaimer and design principles shared by every template here.

| Template | What it does |
|---|---|
| [CRM Hygiene Bot](crm-hygiene-bot/) | Flags stale/incomplete/malformed CRM records on a schedule |
| [Outreach & Follow-Up Automation](outreach-followup-automation/) | Tracks a cadence and exits automatically the moment a prospect replies |
| [Proposal & Quote Generator](proposal-quote-generator/) | Drafts proposals from CRM fields — pricing always human-entered |
| [Pipeline Health Dashboard](pipeline-health-dashboard/) | Stage rollup, average age, stalled deals, win rate |
| [Meeting Intelligence Summarizer](meeting-intelligence-summarizer/) | Call transcript → structured action items + CRM update snippet |
| [Win/Loss Analyzer](win-loss-analyzer/) | Loss-reason frequency and win rate by segment |
| [Territory Balancer](territory-balancer/) | Rebalances account load evenly across reps within capacity |
| [Renewal & Upsell Alert](renewal-upsell-alert/) | Flags upcoming renewals and high-utilization upsell candidates |
| [Quota Attainment Tracker](quota-attainment-tracker/) | Rep attainment % against quota from closed-won deals |
| [Cold Outreach List Deduplicator](list-deduplicator/) | Merges & dedupes prospect lists before a campaign, flags domain overlap |
| [Sales Activity Compliance Checker](activity-compliance-checker/) | Flags open deals with no logged activity past your cadence threshold |
| [Discount Approval Router](discount-approval-router/) | Flags/routes deals needing discount sign-off — never auto-approves |
| [Competitor Mention Tracker](competitor-mention-tracker/) | Tallies competitor mentions in deal notes/transcripts |
| [Lead Enrichment Checker](lead-enrichment-checker/) | Fills missing firmographic fields from a source you already have, flags the rest |
