# Financial Automation Templates

Starter automations mapped onto the Financial Automation course. **Every template in this track is read-only by design — none of them write, post, initiate, or move money, and none ever will.** See the [repo root README](../README.md) for the disclaimer and design principles shared by every template here.

| Template | What it does |
|---|---|
| [Expense Categorization](expense-categorization/) | Rule-based categorization, uncertain items flagged for human review |
| [Reconciliation Assistant](reconciliation/) | Matches bank feed vs. ledger, flags mismatches on both sides |
| [KPI Dashboard Builder](kpi-dashboards/) | Cash runway, burn rate, AR aging, budget vs. actual |
| [Reporting Automation](reporting-automation/) | Assembles a board report from figures you've already verified |
| [Risk & Compliance Flagging](risk-compliance/) | Flags exceptions against your own configured Bright Line — never blocks or initiates |
| [Vendor Spend Analyzer](vendor-spend-analyzer/) | Rolls up spend by vendor/month, flags spend spikes |
| [Subscription/SaaS Spend Auditor](saas-spend-auditor/) | Flags overlapping tool subscriptions by category |
| [Payroll Anomaly Checker](payroll-anomaly-checker/) | Flags new/removed employees and unusual pay changes before approval |
| [Invoice Duplicate Detector](invoice-duplicate-detector/) | Flags exact and near-duplicate invoices before double-payment |
| [Cash Flow Forecaster](cash-flow-forecaster/) | Straight-line projection from historical trend — clearly labeled as such |
| [Tax Deadline Tracker](tax-deadline-tracker/) | Flags approaching filing deadlines from your own tracked list |
| [Fixed Asset Depreciation Calculator](asset-depreciation-calculator/) | Straight-line depreciation schedule, flags end-of-life assets |
| [Vendor Concentration Risk Flagger](vendor-concentration-flagger/) | Flags single-vendor spend concentration risk |
| [Expense Policy Compliance Checker](expense-policy-checker/) | Flags policy-violating expense line items — never approves/rejects |
